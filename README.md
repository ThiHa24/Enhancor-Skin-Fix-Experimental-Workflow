## 🎯 Purpose

The primary goal of this workflow is to enhance AI-generated or plastic-looking skin by:

- Using masked sampling
- Implementing guided CFG
- Controlling denoise
- Refining upscale

With these methods, the workflow improves the authenticity of skin textures effectively.
